# รายชื่อแพทย์เฉพาะทาง (ข้อมูลสาธารณะจากเว็บโรงพยาบาล)

ข้อมูลประกอบหน้า **"หาหมอใกล้ฉัน"** ของแอป [ฉันป่วย](https://bangkho.ac.th/sick7/doctors.html) — โรงเรียนชุมชนวัดบางโค

- ที่มา: หน้า "ค้นหาแพทย์" ที่โรงพยาบาลเผยแพร่เอง (ลิงก์แหล่งอยู่ในคอลัมน์ `hosp[5]`) ดึงด้วย sitemap/หน้าเว็บตาม robots.txt เว้นจังหวะทุกคำขอ
- เก็บเฉพาะ: ชื่อแพทย์ แผนก สาขา/อนุสาขา วันออกตรวจ (ถ้า รพ.ระบุ) — ไม่เก็บเบอร์ส่วนตัวหรือข้อมูลอื่น
- ⚠️ ไม่ใช่การรับรองแพทย์ ข้อมูลเปลี่ยนบ่อย ตรวจใบอนุญาตที่ [checkmd.tmc.or.th](https://checkmd.tmc.or.th/) และโทรยืนยันกับ รพ.ก่อนไป

## ไฟล์
| ไฟล์ | ภาค |
|---|---|
| `data/central.js` | กรุงเทพฯ และปริมณฑล (`const DOCS=`) |
| `data/mid.js` | ภาคกลาง-ตะวันตก |
| `data/east.js` | ภาคตะวันออก |
| `data/ne.js` | ภาคตะวันออกเฉียงเหนือ |
| `data/north.js` | ภาคเหนือ |
| `data/south.js` | ภาคใต้ |

ไฟล์ภาคอื่น (ไม่ใช่ central) เขียนเป็น `(window.DOCSR ||= {}).<ภาค>={...}` · แพทย์แผนจีน (พจ.) มาจากทะเบียน [chinesedoctor.online](https://chinesedoctor.online/) ตรวจใบประกอบโรคศิลปะกับ กรม สบส.

รูปแบบ: `const DOCS={asof, hosp:[[id,ชื่อ,ประเภท,อำเภอ/เขต,โทร,แหล่ง,จังหวัด]], d:[[hid,ชื่อ,แผนก,สาขา,วันออกตรวจ]]}`

ใช้ผ่าน CDN: `https://cdn.jsdelivr.net/gh/krubk12-collab/thai-doctors@main/data/central.js`

## สร้างใหม่
`scripts/fetch_sitemap.sh` ดึงหน้า (แคชในเครื่อง ไม่อยู่ใน repo) → `python scripts/build_docs.py`
